# Jev 微信聊天内嵌分析卡片设计

**日期：** 2026-09-21  
**目标阶段：** Phase 6：微信聊天内嵌式只读分析卡片

## 1. 目标

在用户主动开启实时分析、悬浮窗权限和消息配对后，将 Jev 的结构化分析结果以悬浮覆盖层形式显示在微信对应消息气泡下方，视觉效果接近参考图中的灰色分析卡片：展示情绪、主要意图概率、沟通风险和建议动作。

卡片是 Jev 的 Assistant Surface，不是微信消息。它不写入微信数据库、不调用微信发送接口、不伪装成聊天消息，也不自动回复。现有右上角悬浮胶囊继续作为没有可定位聊天气泡或卡片暂时不可见时的降级入口。

## 2. 非目标

- 不直接修改微信 RecyclerView 或内部聊天 View 层级。
- 不在 Xposed/微信进程中运行分析、网络请求、数据库操作或 Compose UI。
- 不自动发送分析卡片、回复建议或任何微信消息。
- 不保证微信任意版本都能定位气泡；无法定位时必须安全降级。

## 3. 推荐架构

```text
微信消息 Hook
    -> 主 App IPC / MessageCaptureCoordinator
    -> RealtimeAnalysisCoordinator debounce + ConversationAnalyzer
    -> InlineAnalysisCardStore(messageId -> card state)
    -> AccessibilityService 当前窗口快照
    -> InlineAnalysisOverlayService / WindowManager
    -> Compose 分析卡片
```

### 3.1 数据边界

新增的卡片状态只携带：

- 稳定的 `messageId`；
- 当前会话标识的不可逆哈希用于日志和匹配；
- 分析结果中的情绪、意图概率、风险等级、建议动作；
- 卡片生命周期状态和更新时间。

聊天正文继续留在现有受控的 Conversation/History 流程中，不进入日志、WindowManager 参数或 Xposed 模块。卡片状态默认只保存在进程内；历史分析仍由现有加密 Room 保存。

### 3.2 定位策略

AccessibilityService 仅在用户当前允许的微信窗口中读取可见文本节点和 bounds：

1. 根据已捕获消息的可见文本、消息方向和时间邻近关系寻找候选气泡；
2. 过滤输入框、顶部栏、头像和非聊天节点；
3. 选择最接近的消息气泡 bounds；
4. 将卡片放在气泡下方，超出屏幕时向上或向内调整；
5. 窗口滚动、布局变化、切换会话或消息不可见时重新计算；找不到候选时隐藏卡片但保留胶囊状态。

由于 Accessibility 文本可能被截断或微信版本结构变化，定位器必须返回“不确定/未找到”，不能猜测坐标并覆盖其他应用区域。

## 4. UI 与交互

卡片采用紧凑的浅灰/主题表面样式，内容顺序为：

1. `Jev` 标识；
2. 对方当前情绪；
3. 主要意图及概率列表；
4. 沟通风险 `n / 10`；
5. 建议动作摘要。

点击卡片打开主 App 的分析详情，不关闭悬浮服务。悬浮胶囊点击同样打开主 App；关闭悬浮助手仍通过 Jev 设置页完成，避免“点击内容即关闭服务”的歧义。

卡片只展示最新可见分析，默认不堆叠无限历史卡片。若短时间内有新一轮分析，旧卡片按 messageId 替换或隐藏；分析失败显示短暂的错误状态并保留胶囊入口。

## 5. 生命周期与权限

- 实时分析关闭、用户停止悬浮助手、微信离开前台或 IPC 会话失效时，清理卡片并隐藏覆盖层。
- 无障碍权限或悬浮窗权限不足时，不启动卡片定位任务，并通过现有设置页提示用户。
- 卡片服务使用现有用户主动启动的前台悬浮助手生命周期，不因收到消息静默拉起前台服务。
- 应用崩溃、定位失败或微信升级不兼容时，不能影响微信主线程；只降级为隐藏卡片/现有胶囊。

## 6. 测试与验收

### 单元测试

- 卡片状态按 messageId 添加、替换、清理；旧消息不会覆盖新消息。
- bounds 定位器过滤非聊天节点、输入框和无效 bounds，并正确处理上下边界。
- 卡片 ViewModel/渲染状态覆盖 Ready、Visible、Error、Hidden。
- 关闭实时分析和停止服务后卡片状态必为 Hidden。

### Compose / Android 测试

- 卡片展示情绪、意图、风险和建议文本。
- 点击卡片和悬浮胶囊只触发打开主 App，不触发关闭服务或发送消息。
- 长文本、窄屏和屏幕底部消息不溢出。

### 真机验收

- WeChat 8.0.72：发送一条测试消息后，卡片出现在对应气泡下方；快速连续消息只保留最新结果。
- 上下滚动聊天：卡片跟随或在不可见时隐藏，不漂移到错误消息。
- 切换会话、关闭实时分析、停止悬浮助手：卡片立即消失且无自动发送。
- 点击卡片后主 App 打开，悬浮服务仍保持运行。
- 失败/不支持的定位场景仍能使用现有悬浮胶囊入口。
