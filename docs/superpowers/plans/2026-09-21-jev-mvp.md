# Jev AI Relationship Assistant MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a testable Android MVP that accepts a chat transcript, obtains structured Jev analysis and reply suggestions through provider interfaces, and stores successful results locally.

**Architecture:** A Compose/MVVM shell drives a domain use case through `JevAnalyzer`, `ReplyGenerator`, and `HistoryRepository` interfaces. Fake adapters make the first vertical slice deterministic; Retrofit, Room, and DataStore adapters can then be added without changing the screens or domain models.

**Tech Stack:** Kotlin 2.2.10, Android Gradle Plugin 8.11.1, Gradle 8.13, Compose Material 3, Hilt, Retrofit + Gson, Room, DataStore Preferences, Coroutines, JUnit, Compose UI tests.

**Spec:** `docs/superpowers/specs/2026-09-21-jev-mvp-design.md`

## Global Constraints

- `minSdk = 26`; `targetSdk = 35`.
- Use Kotlin + Jetpack Compose + MVVM + Hilt + Room + Retrofit + DataStore + Coroutines.
- No transcript is sent remotely without an explicit user confirmation.
- Domain code cannot depend on Android UI or Retrofit/Room classes.
- Confidence is clamped to `0.0..1.0`; risk is clamped to `0..10`.
- Do not add WeChat accessibility, overlay, Xposed, billing, or vector search to this MVP.
- Every behavior change follows a red-green-refactor test cycle.

## File map

- `settings.gradle.kts`, root `build.gradle.kts`, `gradle.properties`: build configuration.
- `app/build.gradle.kts`, `app/proguard-rules.pro`: Android module and dependencies.
- `app/src/main/AndroidManifest.xml`, `MainActivity.kt`, `JevApplication.kt`: app entry points and Hilt setup.
- `app/src/main/java/com/jev/relationship/core/model/*`: immutable domain models.
- `app/src/main/java/com/jev/relationship/domain/*`: provider and repository contracts plus orchestration use case.
- `app/src/main/java/com/jev/relationship/data/*`: Fake, Retrofit, Room, and DataStore adapters.
- `app/src/main/java/com/jev/relationship/feature/analyze/*`: ViewModel, UI state, input/result screens.
- `app/src/main/java/com/jev/relationship/ui/theme/*`: Compose theme and tokens.
- `app/src/test/*`: pure Kotlin domain and data tests.
- `app/src/androidTest/*`: Compose interaction tests.
